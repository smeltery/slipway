01 / A little breathing room

The same app.
A separate screen.

Build where you always build. Slipway takes the finished app into an isolated macOS desktop, ready for an agent to explore without stealing your focus.

01 /

Ship the build across

One command copies your .app, replaces the running build and waits for its window.

02 /

Read before you click

List controls with labels and coordinates, then click, type or send keyboard shortcuts over SSH.

03 /

Leave a useful trail

03 / Good to know

A few practical
details.

Local tools, explicit permissions, and documentation for the parts that matter.

Does it need Bun to run?

No. The CLI is Bash. Bun runs repository checks and documentation tooling. Tart runs local VMs; cliclick runs inside the guest.

Can I use a spare Mac instead?

Yes. Set TEST_HOST and TEST_USER in the shared configuration, authorize the SSH key and grant the remote permissions.

Can multiple agents click at once?

They share one desktop. Porthole warns about overlapping sessions, but you should coordinate UI input between agents.
